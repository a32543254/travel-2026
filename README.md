# Trip Itinerary PDF Export Guide

This repository contains print-ready HTML and Markdown versions of the itinerary in both Chinese and English.

## Files
- `trip-itinerary-zh.html` — Chinese version, styled for PDF printing
- `trip-itinerary-en.html` — English version, styled for PDF printing
- `trip-itinerary-zh.md` — Chinese Markdown source
- `trip-itinerary-en.md` — English Markdown source

## How to create PDFs
1. Open `trip-itinerary-zh.html` in a browser.
2. Press `Ctrl/Cmd + P`.
3. Choose **Save as PDF**.
4. Repeat for `trip-itinerary-en.html`.

## Notes
- The HTML files are formatted for A4 printing.
- Page breaks, headings, and tables are optimized for PDF export.
